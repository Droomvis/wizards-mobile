Dit project heft als doel een digital kaartspel te ontwerpen. Het doel is dit uiteindelijk te doen in een professionele engine als Godot. 
Momenteel bevinden we ons in de test- en ontwerpfase van zowel de kaarten als de regels.

Binnen dit project heb je al toegang tot enkele files.

Je hebt in kader van dit project toegang tot de map "Wizards" op mijn pc, via {   "mcpServers": {     "filesystem": {       "command": "npx",       "args": [         "-y",         "@modelcontextprotocol/server-filesystem",         "/Users/jouwnaam/Documents/mijn-project"       ]     }   } }.

Die map zelf (/Wizards) bevat de spelregels van het spel, en een to-do lijst waar ik me niet altijd aan hou.
Er is een legacy-submap, waar oudere versies van de applicatie staan.
Er is een development-submap, dat is de versie waar we doorgaans op werken - de architectuur is daar ook beschreven.
Er is een unsorted-submap, daar bewaar ik zaken die nog niet verwerkt zijn.
Er is een "elders gehost" map, waar kopieën van files die ergens gehost zijn beschikbaar zijn.

Dan is er nog een GitWiz-map, die sync ik met GitHub voor publicatie.
